这是一个采用**粉蓝色二次元现代化**风格设计的网页前端项目模板。

## 项目目录结构
```text
IFdReAm/
├── index.html       # 网站主页面
├── css/
│   └── style.css    # 核心全局样式与毛玻璃特效
├── js/
│   └── main.js      # 交互与弹窗逻辑
└── README.md        # 项目说明
```

## 视觉与特色
1. **配色方案**：梦幻柔和的粉（#FFD1DC）与天蓝（#BDE0FE）双色渐变背景。
2. **现代二次元 UI**：采用 Glassmorphism（毛玻璃）、浮动微光粒子与自适应圆角卡片。
3. **流畅交互**：包含微交互按钮反馈与流体弹窗模块。

## 使用方法
直接解压压缩包，双击 `index.html` 即可在浏览器中预览网页。
